在VectorCAST中，如果被测函数在一个测试用例（Test Case）执行期间多次调用同一个桩函数，且您需要该桩函数每次返回不同的值，可以通过**列表值（List Values）**功能来轻松实现。

具体操作步骤和执行机制如下：

**1. 在 Input Values（输入值）列中配置列表** 首先需要明确一个核心概念：桩函数传递回给被测代码的数据（例如桩的返回值 `return` 或出参），在参数树（Parameter Tree）中必须填写在 **Input Values（输入值）**列中，而不是 Expected Values 列，因为这些值是桩函数作为输入“发送”给被测主程序的。

- **快捷输入法**：在参数树中找到被自动打桩的子程序（Stubbed Subprograms），找到其 `return` 参数，直接在 Input Values 单元格中输入以逗号分隔的值列表。例如：`10,20,30`。
- **使用参数对话框**：双击该参数打开参数配置对话框（Parameter Dialog），切换到 **List Values（列表值）** 选项卡。您可以利用界面的 Add 按钮，逐行添加希望桩函数按先后顺序返回的特定标量值。

**2. 列表的动态执行机制**

- **按序响应**：当该测试用例执行时，每次被测代码调用该桩函数，桩函数都会严格按照列表设定的顺序，每次提取并返回列表中的下一个值。
- **列表耗尽处理**：如果被测代码内部包含循环，导致调用该桩函数的次数**大于**您在列表中设定的值的数量，那么一旦列表元素被用完，桩函数将在后续的所有调用中**一直重复返回列表里的最后一个值**。
- **作用域重置**：默认情况下，每次对被测单元（UUT）发起全新的调用时，这个桩函数的多重返回列表都会被重置回第一个起始项。

**3. 进阶处理：控制大量的重复返回值** 如果被测代码会疯狂调用该桩函数（例如在一个大的 `while` 循环中），并且您希望它前 80 次调用都返回 `10`，接着的 20 次调用返回 `0`。您无需手动输入 100 个值，可以利用**重复计数（Repeat count）**：

- 在 List Values 选项卡中，每一行都有一个 `repeat` 列。您可以第一行写 `repeat` 80、`value` 10；第二行写 `repeat` 20、`value` 0。
- 如果在 UI 直接以文本语法输入，可以使用带括号的重复次数格式，例如：`(80)10, (20)0`。

**4. 跨迭代高级控制（Return Data List Options）** 如果您配置的是包含多次迭代的范围测试（Range Testing）或组合测试（Compound Test），并且您希望桩的返回值列表**不要**在每次迭代开始时被重置，而是跨越多个用例周期连贯地消耗列表数据。您可以在用例底部的 **Options** 选项卡中，勾选 **Multi-returns spans range iterations**（多返回值跨越范围迭代）或 **Multi-return spans compound iterations**（多返回值跨越组合槽迭代）选项。
